Privacy Policy

Tab Organizer Pro

Last updated: April 6, 2026

Tab Organizer Pro does not collect, sell, or transmit personal data to any remote server. The extension uses local Chrome extension storage only to provide its core tab-management features.

What the extension accesses

The extension uses the following Chrome extension permissions:

  • `tabs`: used to read tab titles, URLs, pinned state, window placement, and last-accessed metadata so tabs can be organized, searched, cleaned up, and restored.
  • `storage`: used to save extension settings, session snapshots, and the Read Later / TODO list on the user's device through Chrome storage.
  • `alarms`: used to run optional scheduled auto-organization at user-selected times.

How data is used

All tab data accessed by the extension is used only to provide the extension's core features:

  • organize tabs into windows
  • search and activate existing tabs
  • identify duplicate or stale tabs
  • save and restore the last session snapshot
  • maintain the Read Later / TODO list
  • run scheduled organization jobs

Data storage

The extension stores data locally in Chrome's extension storage areas:

  • `chrome.storage.sync` for user settings
  • `chrome.storage.local` for session snapshots and Read Later items

The extension does not send this data to the developer or to third-party services.

Third-party services

Tab Organizer Pro does not use analytics, ads, tracking scripts, or remote code.

Changes

If this privacy policy changes, updates will be published in this repository.
